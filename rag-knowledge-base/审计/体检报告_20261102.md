## 二、代码审查发现与修复

| 级别 | 问题 | 修复 |
|---|---|---|
| **P0** | 服务绑定 `0.0.0.0` 且无鉴权，局域网可删档/重建 | 默认绑 `127.0.0.1`，需局域网访问时显式 `HOST=0.0.0.0` |
| **P1** | `.txt` 可上传但 `load_docs` 只读 `.md`（上传了却检索不到） | `load_docs` 同时支持 `.md/.txt`；体检新增用例验证 |
| **P1** | 无 `##` 的短文档（<300 字）整篇被丢弃 | 阈值改为 80，仅跳过纯标题/说明块 |
| **P1** | 路径穿越文件名被 basename 静默接受 | 含 `..` 或路径分隔符直接拒绝 |
| **P1** | 重建索引无锁，并发 ask 可能命中空集合 | 重建加互斥锁，冲突返回 409 |
| **P1** | 上传无大小限制、单文件异常中断整批 | 单文件限 2MB、逐文件 try/except |
| **P1** | question 非字符串 / history 非数组 / JSON 非对象会 500 | 类型校验后返回 400 或安全降级 |
| **P1** | app.py 硬编码 docs 目录，与 config 不一致 | 统一读 `config.docs_dir` |
| **P1** | 界面缺反馈控件（文档却写了反馈） | 每条回答下加「有用/没用」，写入 feedback.jsonl |
| **P2** | 候选池 `top_k*3` 去重后可能不足 top_k | 扩大到 `top_k*6` |
| **P2** | `overlap>=size` 时产生重复块膨胀 | 构建时钳制 `overlap<=size/2` |
| **P2** | embedding 模型冷启动并发重复加载 | 双重检查加锁 |
| **P2** | `/api/docs` 整读文件估算字数（大文件 OOM 风险） | 改用文件大小估算 |

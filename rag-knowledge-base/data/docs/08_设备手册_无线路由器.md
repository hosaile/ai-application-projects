# 千兆无线路由器配置手册

## 一、接口与默认参数

| 项目 | 说明 |
|---|---|
| WAN 口 | 连接光猫 LAN 口或入户网线 |
| LAN 口 | 连接电脑、交换机、NVR 等设备 |
| 管理地址 | 常见为 192.168.0.1 或 192.168.1.1，以标签为准 |
| 默认账号 | 见机身标签，首次登录后修改 |
| 无线默认 | 双频合一或 2.4G/5G 分开，名称见标签 |

## 二、上网配置

1. 光猫路由模式：路由器 WAN 设置为自动获取 IP（DHCP）。
2. 光猫桥接模式：路由器 WAN 设置为 PPPoE，填写宽带账号密码。
3. 保存后查看 WAN 状态，获取到公网或运营商内网地址即为成功。

## 三、无线配置建议

1. 2.4G 穿墙强、干扰多；5G 速度快、覆盖近。建议分开命名便于选择。
2. 信道选择：2.4G 选 1/6/11，5G 选 149 以上以减少干扰。
3. 加密方式选 WPA2/WPA3，禁用 WEP。
4. 访客网络单独开启，隔离内网设备。

## 四、常见故障处理

### 4.1 连上 WiFi 但无法上网
- 先在路由器管理页查看 WAN 是否获取到地址。
- 检查宽带是否欠费、光猫是否 LOS 红灯。
- 尝试重启光猫与路由器（间隔 30 秒）。

### 4.2 频繁掉线
- 检查散热，路由器长期高温会降频重启。
- 2.4G 干扰严重时切换信道或改用 5G。
- 连接设备过多（超过 30 台）建议增加 AP 或升级设备。

### 4.3 IP 冲突
- 路由器 LAN 网段不要与光猫相同（如光猫 192.168.1.1，路由器 LAN 改为 192.168.2.1）。
- 关闭冲突设备的静态 IP，或统一由 DHCP 分配。

### 4.4 无法进入管理页面
- 确认电脑与路由器在同一网段。
- 清除浏览器缓存或换浏览器。
- 长按 Reset 恢复出厂后重新配置。

## 五、安全与维护

1. 修改默认管理密码，关闭 WAN 侧远程管理。
2. 定期检查固件更新，修复已知漏洞。
3. 关闭 WPS 功能，防止被暴力破解。
4. 记录宽带账号、WiFi 密码，贴于设备底部便于维护。

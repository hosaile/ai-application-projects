# 接入层交换机配置与维护手册

## 一、设备概述

本手册适用于小型办公与监控项目使用的二层/三层接入交换机，用于终端接入、VLAN 划分与 PoE 供电。

## 二、基础配置

1. 使用 Console 线连接交换机与电脑，终端软件波特率一般 9600。
2. 登录后先修改管理密码，配置管理 IP（与办公网同网段）。
3. 保存配置（write 或 save），避免断电丢失。

## 三、VLAN 划分

1. 创建 VLAN：例如 VLAN 10 办公、VLAN 20 监控、VLAN 30 访客。
2. 接入端口设为 Access 模式并加入对应 VLAN。
3. 上联端口设为 Trunk，允许所需 VLAN 通过。
4. 三层交换机需配置 VLAN 接口地址作为网关。

## 四、常见故障处理

### 4.1 端口不亮
- 检查网线与水晶头，使用测线仪确认 8 芯通断。
- 确认对端设备已上电。
- 尝试更换端口，排除端口损坏。

### 4.2 接上交换机不通
- 确认端口 VLAN 与对端一致。
- 检查端口是否被 shutdown（管理页查看状态）。
- 确认终端 IP 与网关配置正确。

### 4.3 网络时通时断、广播风暴
- 检查是否存在环路（同一根网线两端接同一交换机）。
- 建议开启 STP/RSTP，或启用端口环路检测。
- 排查私接路由器、劣质网线。

### 4.4 PoE 摄像头不上电
- 确认交换机 PoE 总功率与单口功率足够（单口 15.4W/30W）。
- 检查端口是否开启 PoE 供电。
- 网线过长或线径不足会导致压降过大。

## 五、维护与安全

1. 关闭未使用端口，防止私接。
2. 开启端口安全，限制 MAC 数量。
3. 定期备份配置文件。
4. 管理 VLAN 与业务 VLAN 隔离，管理地址仅运维网段可访问。

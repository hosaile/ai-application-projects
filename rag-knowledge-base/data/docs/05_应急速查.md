# 五、应急速查（3 个场景）

> 网络排障助手 知识库 · 共 23 个场景 · 内容整理自实训资料与常见故障处理经验 · 以实际设备为准

## 5.1 停电 / 关机后的恢复顺序

**现象**：停电恢复后、或维护关机后，需要按顺序把设备恢复起来。

**30 秒快速判断**：顺序口诀：光猫 → 路由 → 交换机 → NVR / 服务器 → 终端。每级上电后等指示灯稳定（1-2 分钟）再开下一级——上级就绪了，下级才能顺利拿到地址。

**排查步骤**：
1. 确认总电 / 排插已通电（看排插指示灯）
2. 开光猫：等 PWR 常亮、PON 常亮（约 2-3 分钟）
3. 开主路由器：等指示灯稳定、手机能连上（1-2 分钟）
4. 开主交换机：看各口灯进入正常闪烁
5. 开 NVR / 服务器：跟显示器确认画面 / 服务正常
6. 开电脑和终端设备，逐台验证上网
7. 整体抽查：打开几个网页、看监控画面、验证业务系统（收银 / 办公系统等）

**老师傅提示**：
- 关机顺序反过来：终端 → NVR → 交换机 → 路由 → 光猫。
- 长期不用的设备别骤停骤起；来电瞬间电压不稳，重要设备建议用带保护的排插。

**什么时候必须上报**：恢复后个别设备仍异常 → 单独排查那一台，不要反复整体重启。

**对客户话术**：「来电 / 维护后我按顺序恢复设备，十分钟内全部检查一遍。」

## 5.2 机房 / 弱电间巡检「5 看」

**现象**：日常巡检，或客户说「你去机房看看」时用。

**30 秒快速判断**：五句话：看灯、听声、闻味、摸温、查线。走一圈三分钟，能提前发现大半隐患。

**排查步骤**：
1. 看灯：光猫 PON / LOS、交换机各口——有没有不亮的、狂闪的、告警灯亮的
2. 听声：风扇异响、设备报警声、异常的嗡鸣
3. 闻味：有没有焦糊味——有的话立即上报，可能过热或短路
4. 摸温（允许触碰的设备）：外壳明显烫手（比体温高很多）= 散热问题，查灰尘和通风
5. 查线：私接乱拉、线被压住拉紧、接头松动、标签脱落
6. 拍照记录：异常处拍照，写进巡检记录（时间、现象、处理），下次对比

**老师傅提示**：
- 巡检的价值在记录：攒下来的记录能看出设备「什么时候开始变差」。
- 弱电间严禁堆放杂物，尤其易燃物；这既是规范也是保命。

**什么时候必须上报**：焦糊味、打火痕迹、大量设备异常 → 立即报告、必要时断电；涉及强电叫持证电工。

**对客户话术**：「我巡检一圈，几分钟，有异常我拍照记录给您。」

## 5.3 什么时候必须上报 / 不能自己动

**现象**：遇到搞不定的故障，或不确定该不该动手时，先看这条。

**30 秒快速判断**：三不动：强电不动、光纤不动、客户核心设备不动。三必报：有危险必报、超权限必报、影响面大必报。

**排查步骤**：
1. 光猫 LOS 红灯（光纤故障）→ 不动手，报运营商
2. 涉及 220V 强电、配电箱、打火 / 焦糊味 → 不碰，找持证电工
3. 客户核心设备（服务器 / 主交换机 / 收银系统）要改配置 → 先获批、先备份再动
4. 高空作业（外墙摄像头、高杆）→ 两人配合、系安全护具，不独自登高
5. 网络大面积瘫痪、找不到原因 → 先汇报现象，不盲目试错扩大影响
6. 需要拆客户设备封条、涉及数据安全 → 先口头 / 书面确认再操作

**老师傅提示**：
- 上报带齐 4 样东西：什么现象、什么时候开始、做过什么、现在什么状态——能省一轮来回。
- 操作前备份配置、拍照留底，是职业习惯，不是胆小。

**对客户话术**：「这个情况需要专业人员处理，我先把现场记录好，帮您对接处理。」

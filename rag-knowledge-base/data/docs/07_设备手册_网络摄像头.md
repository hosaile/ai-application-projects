# 网络摄像头（IPC）安装与维护手册

## 一、设备概述

本手册适用于 PoE 供电或 12V 独立供电的网络摄像头（IPC），支持 ONVIF 协议，可接入 NVR 或监控平台。

## 二、安装前准备

1. 确认供电方式：PoE 供电需接入 PoE 交换机或 PoE 注入器；独立供电需 12V/1A 适配器。
2. 网线建议使用超五类或六类线，单段长度不超过 100 米。
3. 室外安装需选用防水型号，接头处做防水处理（防水胶带 + 接线盒）。
4. 安装高度建议 2.5 米至 3.5 米，避免逆光直对窗户。

## 三、接线与初始化

1. 网线插入摄像头网口，PoE 型号上电后红外灯短暂亮起表示启动。
2. 使用厂商 IP 搜索工具或扫描网段找到设备默认地址。
3. 首次登录必须设置强密码，禁止使用 admin/12345 等默认口令。
4. 在 NVR 或平台中添加设备：填写 IP、端口（默认 554 或厂商私有端口）、账号密码。

## 四、常见故障处理

### 4.1 摄像头不上电
- 检查 PoE 交换机端口指示灯是否亮起，端口供电功率是否足够（单口一般 15.4W）。
- 独立供电时测量适配器输出电压是否为 12V。
- 网线水晶头是否压接良好，可用测线仪测试 8 芯通断。

### 4.2 能 ping 通但无画面
- 确认添加设备时使用的协议与端口正确。
- 检查摄像头是否被其他平台占用（部分设备限制同时连接数）。
- 核对账号密码，多次错误可能触发锁定。

### 4.3 画面花屏、卡顿
- 降低码率或分辨率测试，排除带宽不足。
- 检查交换机上行链路是否拥塞，多路高清建议千兆上联。
- 网线质量差或距离超 100 米会导致丢包花屏。

### 4.4 夜间画面全黑或红外不亮
- 检查光敏元件是否被遮挡。
- 红外灯板供电异常需返修。
- 镜头前玻璃起雾可用防雾剂处理。

### 4.5 录像丢失
- 检查 NVR 硬盘状态与录像计划是否开启。
- 确认时间同步，时间错乱会导致录像检索不到。
- 硬盘满后的覆盖策略需设置为循环覆盖。

## 五、维护与安全

1. 每季度检查镜头清洁度与防水胶带老化情况。
2. 固件升级前备份配置，升级过程禁止断电。
3. 严禁将摄像头管理端口直接映射到公网，远程访问应使用 VPN 或厂商云服务。
4. 定期更换密码，离职人员账号及时删除。

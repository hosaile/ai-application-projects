# 二、网络设备（5 个场景）

> 网络排障助手 知识库 · 共 23 个场景 · 内容整理自实训资料与常见故障处理经验 · 以实际设备为准

## 2.1 交换机某个端口指示灯不亮

**现象**：机柜里交换机一个口插了线但灯不亮，接在这口的设备上不了网。

**30 秒快速判断**：换一根确定好的网线测同一个口：灯亮 = 线的问题；灯不亮 = 换个空口测：新口亮 = 原端口问题；都不亮 = 对端设备没开机或没供电。

**可能原因（按概率）**：
- 高：网线 / 水晶头问题：没压好、断芯、劣质线
- 中：对端设备没开机、网卡坏、PoE 没供电
- 中：端口被软件禁用或端口故障
- 低：速率协商失败（少见）

**排查步骤**：
1. 拿一根正在用的好网线插原来这个口 → 灯亮说明原网线有问题，重做 / 更换
2. 原网线插一个空口 → 灯亮说明原端口有问题，避开这个口；管理型交换机可登录检查该口配置
3. 换线换口都不亮 → 问题在对端：确认对端设备开没开机（摄像头 / AP 看电源灯）
4. 对端是摄像头、AP 等 PoE 设备 → 看交换机是不是 PoE 款、这个口有没有供电，走「PoE 不上电」流程
5. 判断线好坏：看两头水晶头压没压紧、线序对不对；用手轻拉，一拉就掉的直接换
6. 坏线重做水晶头：线序 T568B——橙白 橙 绿白 蓝 蓝白 绿 棕白 棕，1、2、3、6 芯是关键

**老师傅提示**：
- 现场判断口诀：先换线、再换口、最后查对端。
- 水晶头 T568B 线序背下来：橙白、橙、绿白、蓝、蓝白、绿、棕白、棕。

**什么时候必须上报**：多个端口同时不亮 / 整机无电 → 检查交换机电源，必要时带备用交换机更换；端口被软件禁用需要管理员账号。

**对客户话术**：「就这一个口的问题，我换线换口测一下，马上能定位。」

## 2.2 Ping 不通某台设备 / 搜不到设备

**现象**：电脑 ping 设备 IP（摄像头 / 服务器 / 打印机）不通，访问不了。

**30 秒快速判断**：按「分层」查：① 物理层——设备灯亮不亮、线松没松；② 网络层——电脑和设备是不是同一网段；③ 设备层——设备死没死机、防火墙拦没拦。一层层往下走，别跳步。

**可能原因（按概率）**：
- 高：物理不通：网线 / 端口问题
- 高：电脑和目标设备不在同一网段
- 中：目标设备死机 / 离线
- 中：目标设备防火墙禁 ping（其实在线）
- 低：两端在不同 VLAN，被隔离

**排查步骤**：
1. 看物理：设备电源灯、网口灯；线两头插紧；设备断电重启一次
2. 看电脑 IP：ipconfig——和目标前三段数字一样才是同网段（192.168.1.x 和 192.168.1.y 同段）
3. 同网段仍不通 → 电脑网线直连设备绕过交换机：通了 = 交换机或线路问题（换口）；不通 = 设备问题
4. 电脑 IP 改成和设备同网段再试；摄像头用厂商工具扫（海康 SADP、大华 ConfigTool）
5. 能搜到设备但 ping 不通 → 多半是设备防火墙禁 ping，直接用浏览器打开设备 IP 验证是否在线
6. 确认 VLAN：设备接的口和电脑在不在同一个 VLAN / 网段

**老师傅提示**：
- 排「ping 不通」永远从物理层开始：先看灯、再看 IP、最后敲命令。
- 同网段的判断方法：三个数字一样（前三段），不一样就先改电脑地址再测。

**什么时候必须上报**：换线、换口、直连都不通 → 设备本身故障，联系厂商售后或更换。

**对客户话术**：「我从最基础的查起：先看线和设备状态，再对地址，一步步来。」

## 2.3 跨网段 / 不同 VLAN 之间不通

**现象**：同网段内能通，跨 VLAN / 跨网段访问不了（如办公网访问不到监控网）。

**30 秒快速判断**：先分别在两边网段内互 ping 验证各自正常，再查跨网段的「桥」——终端网关填得对不对、三层设备做没做 VLAN 间路由、有没有 ACL 拦截。

**可能原因（按概率）**：
- 高：终端网关配置不正确
- 中：三层设备上没做 VLAN 间路由
- 中：ACL / 防火墙拦截了跨网段访问
- 低：路由表缺失

**排查步骤**：
1. A 网段内互 ping、B 网段内互 ping——各自都正常再查跨段
2. 看终端网关：ipconfig 的默认网关是不是本网段的网关地址
3. 检查三层设备（路由器 / 三层交换机）有没有开 VLAN 间路由
4. 检查 ACL / 访问控制策略有没有拦来源或目标网段
5. 用 tracert 追一下：看数据包走到哪一跳断，断点前后就是问题区

**老师傅提示**：
- 跨网段排障答三句话：网关对不对、路由有没有、策略拦没拦。
- 动核心设备配置前先备份——这是职业习惯，不是胆小。

**什么时候必须上报**：涉及核心设备配置修改 → 先备份配置，改动向主管 / 客户确认后再做；不确定不动手。

**对客户话术**：「两个网段各自都是通的，我在检查中间的转发配置，需要几分钟。」

## 2.4 网络环路 / 广播风暴（全网络瘫痪）

**现象**：网络突然极慢甚至全瘫，交换机指示灯全部疯狂闪烁。

**30 秒快速判断**：看交换机灯：所有口的灯一起高频狂闪 → 基本就是环路。回忆一下刚才谁动过线、加过设备——八成和那个操作有关。

**可能原因（按概率）**：
- 高：网线两头都插在同一台交换机上（自己连自己）
- 高：新增设备接线成回路（两台交换机之间接了两根线）
- 中：墙里面板 / 模块接线错误形成环路

**排查步骤**：
1. 确认现象：所有端口灯同步狂闪、网络几乎不可用 → 立即行动，恢复优先
2. 回忆最近改动：刚插的线、刚加的设备——先拔掉它 → 网络立即恢复 = 找到环了
3. 找不到是哪根 → 逐根拔插：拔一根观察几秒，灯恢复正常就是它（提前和客户说好会短暂断网）
4. 恢复后复盘接线：确认整个拓扑是「树状」而不是「圈」
5. 有条件在管理型交换机上开启 STP（生成树协议）防复发，并能查看端口流量定位异常口
6. 给客户交代：不乱插网线，新增设备先报备

**老师傅提示**：
- 环路是人为事故里最高频的——「刚动完线就出问题」，先怀疑刚动的那根。
- 处理环路的核心是快：先拔线恢复网络，再慢慢找原因。

**什么时候必须上报**：找不到环路来源、网络反复瘫痪 → 上报并启用 STP；把本次处理和原因写进记录。

**对客户话术**：「网络先恢复：我逐根检查线，中间可能会断一下，很快就好了。」

## 2.5 光猫指示灯异常（LOS 红灯）

**现象**：光猫上红灯闪烁或常亮（标着 LOS 或「光信号」），上不了网。

**30 秒快速判断**：看 LOS（光信号）灯：红灯闪 / 常亮 = 光纤链路故障。自己能做的只有两件事：① 检查光纤接头插没插紧 ② 重启光猫；都不行 → 直接报运营商。

**可能原因（按概率）**：
- 高：光纤线路故障：外力断纤、运营商机房侧问题
- 中：光猫背面光纤接头松动 / 脏污
- 中：宽带欠费被停（部分表现为收光正常但上不了网）
- 低：光猫设备故障

**排查步骤**：
1. 先读懂灯语：PWR = 电源；PON = 注册（常亮正常、闪烁 = 注册中/异常）；LOS / 光信号 = 正常情况下熄灭，红灯闪 / 常亮 = 线路故障
2. 检查光猫背面黄色光纤接头：轻轻拔下看一眼、重新插紧（有轻响）；光纤很脆，禁止用力弯折
3. 重启光猫：断电 30 秒再上电，等 2-3 分钟看 PON 能不能恢复常亮
4. 红灯依旧 → 光纤或运营商侧故障：让客户拨打运营商客服报修，说清「光猫 LOS 红灯，检查接头并重启无效」
5. 问一下客服是不是片区 / 小区故障——是就等恢复，不用折腾设备
6. 修好后测速验证上网，把处理和故障单号记在运维记录上

**老师傅提示**：
- 华为 / 中兴光猫告警灯颜色略有差异（红或橙）——记「有没有告警灯亮」就行。
- LOS = Loss of Signal（信号丢失）。光纤严禁自己熔接、严禁大角度折弯。

**什么时候必须上报**：LOS 红灯 + 接头插紧 + 重启无效 → 只能报运营商；记下故障单号，客户催就报单号跟进。

**对客户话术**：「这是光纤线路的故障，光猫收不到光信号。我帮您检查接头，如果不行需要打运营商电话报修——我可以帮您把故障说清楚。」

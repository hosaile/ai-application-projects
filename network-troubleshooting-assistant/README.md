# 网络排障助手

面向弱电与网络设备的排障知识库工具。输入故障现象，直接给出分步排查步骤。

## 特点

- **5 大类 23 个故障场景、141 步排查**
  - 上不了网 / 网络设备 / 监控弱电 / 终端办公 / 应急速查
- 每个场景统一结构：**现象 → 30 秒快速判断 → 原因概率排序 → 分步排查 → 升级条件 → 对客户话术**
- 搜索即出步骤、可勾选、一键复制排查结果
- 单文件 HTML，**零依赖、离线可用**，手机浏览器可直接打开

## 使用

直接双击 `网络排障助手.html`（或手机浏览器打开），输入现象关键词即可。

配套材料：
- `使用说明.txt`：使用与维护说明

## 结构说明

故障场景按目录组织，每个场景包含：

| 字段 | 含义 |
|---|---|
| 现象 | 用户描述与典型表现 |
| 快速判断 | 30 秒内缩小范围的方法 |
| 原因（按概率） | 高/中/低概率原因排序 |
| 排查步骤 | 分步操作，含判断标准 |
| 升级条件 | 何时必须上报，不自行处理 |
| 话术 | 对客户/老师的沟通用语 |

## 说明

知识内容整理自实训资料与常见故障处理经验，实际设备以厂商文档为准。演示用途，不含真实客户信息。

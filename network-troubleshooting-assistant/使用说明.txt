========================================
网络排障助手 · 使用说明
========================================

■ 你现在手里有 3 个版本（知识内容一致，用法不同）

1）网页版：网络排障助手.html
   单文件、离线可用、手机电脑都能开。主要用它演示和日常查故障。
   电脑和手机是同一套界面，会自动切换，不需要手动选：
     · 电脑（窗口 ≥1024px）：左边竖排导航 + 中间正文 + 右边注解栏，
       搜索框按 / 聚焦，↑↓ 选场景、回车打开，P 打印当前场景。
     · 手机 / 平板窄屏：单栏，顶部搜索框常驻，底部有「返回 / 复制排查结果」快捷条。
   把窗口拉宽拉窄，布局当场切换；横竖屏、折叠屏展开同理。
   小细节：
     · 手机上按系统返回键会回到列表；故障页的排查步骤可点一下勾选，
       「排查步骤」那段标题右边有进度（已勾 x/y）；
     · 部分场景有「常用命令」，点一下就复制（如 ipconfig、ping），到 cmd 里粘贴执行；
     · 需要打运营商电话的场景（整楼断网、光猫红灯），上报那段里有电信 / 移动 /
       联通的按钮，手机上点一下直接拨号；
     · 卡片右上角和场景标题旁边的星标是收藏，常用的场景标上，首页顶部和左栏
       会单独列出来，不用每次都搜；最近看过的几个场景也会记在首页和左栏。
2）AI 版：AI助手提示词_粘贴即用.txt
   粘贴到豆包 / 元宝 / Kimi / DeepSeek，就是一个会对话的 AI 排障助手；
   按里面第【用法二】在豆包建智能体，还能分享给别人用。
3）文档版：知识库\ 文件夹（6 个 md 文件）
   全库单文件 + 按 5 大类分册，适合打印、发人、或上传到平台做知识库。

另外还有一份「作品说明一页纸」：一页纸案例.pdf / 一页纸案例.png
   投递时在 BOSS / 微信聊天里直接发给 HR 或技术主管，一页看完这个工具是什么、能干什么。

■ 怎么在手机上打开网页版（推荐）？

【安卓】把"网络排障助手.html"用 QQ / 微信发给自己（文件传输助手）→
  手机点开文件 → 选择"用其他应用打开" → 选浏览器（Chrome/自带浏览器/夸克都行）。
【iPhone】同上发送文件 → 点开后如果显示的是源代码，
  选择"用其他应用打开"→ 夸克 / QQ浏览器 / Chrome 打开；不行就用电脑演示，效果一样。
【电脑】直接双击 "网络排障助手.html" 就行，不需要装任何东西、不需要联网。

小技巧：提前把文件存到手机"文件"或浏览器收藏，面试前 30 秒检查能不能打开。

■ 面试 / 电话里怎么用它（30 秒版）

「我平时爱折腾网络排障，就把常见故障整理成了一个小工具，手机上就能查。」
→ 打开网页，随便输入一个故障（如：监控黑屏）
→ 指着屏幕说：「它先让我做 30 秒快速判断，这一步是分层排查法：先物理层，再网络层。」
→ 收尾：「知识库是我整理的，5 大类 23 个场景；工具是我用 AI Agent 辅助做出来的。」

如果对方追问「这不就是个搜索框吗 / AI 写的吧」，可以这么答：
  · 「不是搜索，是排查手册。搜到之后给的是有先后顺序的动作，每步都带判断标准，
     而且按物理层→网络层→设备层的顺序走，跟老师傅的实际习惯一致。」
  · 「离线能用。全部内容打包在一个 HTML 文件里，地下室、电梯、没信号的地方都能查。」
  · 「经验是我自己整理的，AI 只负责把结构化的内容做成工具。」
  · 「还能打印成现场作业单，勾了哪些步骤打出来就是哪些。」

■ 想改内容 / 改样式怎么办？

改内容，两个办法：
1. 最省事：在 ZCode 里直接说，例如"把'摄像头离线'这步改成 xxx"，重新生成。
2. 自己改：编辑 _构建\data\ 里的 json 文件 → 在本文件夹运行命令：
      node _构建\build.js
   会自动重新生成网页版和全部文档。改完搜一下确认没写错。

场景支持两个可选字段（不写就不显示）：
  cmds：常用命令，如 {"t":"查本机地址","c":"ipconfig"}，场景页点一下复制；
  tels：电话按钮，如 {"t":"电信","n":"10000"}，手机上点一下直接拨号。
改完跑一遍自测，qa.js 会校验这两个字段的形状。

改样式（配色、版面、文字）：
  网页版的界面全部写在 _构建\template.html 一个文件里，改完同样运行
  node _构建\build.js 即可。改样式不要直接动 网络排障助手.html，
  下次构建会被覆盖。

改完自测（不需要浏览器，Node 里跑）：
      node _构建\qa.js
  会跑一遍 36 条搜索用例、边界情况和数据完整性，全过才算没改坏。

「作品说明一页纸」重新出图（改过知识库数字后要跑）：
      node _构建\onepager\build-onepager.js
  这一条会自动：把知识库统计数字（大类 / 场景 / 步骤 / 字数）填进一页纸
  → 用 headless Chrome 以 3 倍像素渲染 → 重新导出根目录的 PDF 和 PNG。
  所以一页纸上的数字不用手写，加了场景重跑就跟上。
  一页纸的版式改 _构建\onepager\onepager.html；里面 <span data-stat="xxx">
  的位置会被自动填数，不用自己改数字。
  （如果网页长什么样变了，先跑 python _构建\onepager\_shoot.py 重拍手机截图，
    再跑上面那条出图命令。）

AI 提示词（AI助手提示词_粘贴即用.txt）的用法说明是手写的，
但里面的【知识库摘要】由构建自动生成：改 _构建\data\ 里的 json 后跑
  node _构建\build.js
摘要（标题 + 30 秒快速判断 + 常用命令 + 报修电话）会自动重写。
想改摘要的生成规则，改 _构建\prompt-summary.js 这一个文件，
build.js 和 qa.js 共用它。qa.js 会逐行比对 txt 和 json，
改了数据没重跑 build 的话，自测直接 FAIL 并点名是哪个场景。

■ 想打印一份带到现场怎么办？

打开任意故障场景，「排查步骤」那段下方有一排按钮，点「打印作业单」：
  · 电脑：按钮在那一段里，右边注解栏也有一份
  · 手机：同样在这一段，往下划一点就能看到
打印出来的是一张干净的 A4/A5 清单，页眉带日期和分类，内容依次是：
分类、现象、30 秒快速判断、可能原因、排查步骤、常用命令、上报红线、
对客户话术（含电话号码）。
步骤带 ☐ 勾选框，已经勾过的会打成 ☑，到现场照着划就行。
导航栏、按钮、颜色块会自动去掉，不浪费墨。

■ 隐私与安全

- 网页版所有内容都打包在这一个文件里，不联网、不上传任何数据。
- 搜索、步骤、勾选、复制、打印，全程零联网，断网也能用。
- 只有在「设置 → AI 增强」里填了 Key 之后才会联网，而且也只有你在故障页
  手动点「问 AI」/ 按回车的那一次才发请求，没有后台自动调用。
  发出去的只有：你输入的那句话、最多 3 条知识库条目的标题 / 可能原因 / 排查步骤，
  以及最近 6 轮问答记录（用来支持连续追问）。
  现象、上报红线、对客户话术这些不外发。请求直连你自己选的平台，不过第三方。
- AI 对话记录只存在内存里，关掉页面就没了，不写进浏览器存储。
- Key 只存在本机浏览器（localStorage），不上传到别处；点「清除」即删除。
  ⚠ 别把已经填好 Key 的文件发给别人，对方拿到就能用你的额度。
- 知识库内容以实际设备为准，现场拿不准的先测试再动手。
  涉及强电、光纤熔接、高空作业、客户核心设备，按页面上的「必须上报」提示走。

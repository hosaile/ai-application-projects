# 四、终端办公（4 个场景）

> 网络排障助手 知识库 · 共 23 个场景 · 内容整理自实训资料与常见故障处理经验 · 以实际设备为准

## 4.1 IP 地址冲突

**现象**：电脑弹窗「检测到 IP 地址冲突」，上网一会好一会断。

**30 秒快速判断**：看这台电脑是不是手动设了固定 IP——冲突的另一台多半是有人随手设了同一个地址。最快解法：改成自动获取，或换一个没人用的 IP。

**可能原因（按概率）**：
- 高：两台设备手动设了同一个固定 IP
- 中：固定 IP 落在路由器自动分配的范围里，撞上被分出去的地址
- 低：设备故障乱发地址（少见）

**排查步骤**：
1. 看本机是自动获取还是固定 IP：ipconfig /all 里看 DHCP 是否启用
2. 固定 IP 的：先改成自动获取测试；确需固定 → 换规划外的地址并登记台账
3. 自动获取的：cmd 里 ipconfig /release 再 ipconfig /renew 重新拿地址
4. 找冲突源：路由器 DHCP 客户端列表里看该 IP，或交换机上看该 IP 对应几个 MAC，对照设备清单找到那台
5. 补台账：哪些 IP 留给固定设备、哪段给自动分配，写清楚，从根上防冲突

**老师傅提示**：
- 冲突的根因九成是「有人随手设了个固定 IP」。
- 解决靠台账规划，不靠反复重启。

**什么时候必须上报**：找不到冲突源、反复冲突 → 用扫描工具（如 Advanced IP Scanner）扫全网段，重新规划 IP。

**对客户话术**：「是两台设备用了同一个地址，我帮您把地址理顺，以后就不会再冲了。」

## 4.2 打印机脱机 / 打不出来

**现象**：点了打印没反应，打印机显示「脱机」。

**30 秒快速判断**：先看打印机屏幕 / 灯有没有报错（缺纸、卡纸、缺墨），再把打印队列「取消所有文档」重打——一半问题到这就解决了。

**可能原因（按概率）**：
- 高：打印队列卡了旧任务
- 高：打印机网络 / 线缆断开（IP 变了、USB 松了）
- 中：驱动异常 / 端口选错
- 低：缺纸、卡纸、耗材用尽

**排查步骤**：
1. 看打印机本体：电源灯、屏幕报错（缺纸 / 卡纸 / 墨粉）
2. 清队列：设备和打印机 → 右键打印机 → 查看打印队列 → 取消所有文档
3. 网络打印机：在打印机屏幕上查 IP → 电脑 ping 通不通；不通 → 打印机网络掉了（重启打印机、查网线）
4. USB 打印机：换 USB 口、换线；换一台电脑测
5. 查端口：打印机属性 → 端口 → 确认指向正确 IP / 端口（打印机改过 IP 的要同步更新）
6. 重装驱动：去官网按型号下载，别用万能驱动

**老师傅提示**：
- 顺序：先清队列 → 再看连通 → 最后查驱动。顺序对了省一半时间。
- 网络打印机建议在路由器里给它固定 IP，避免「换了 IP 就脱机」。

**什么时候必须上报**：硬件报错（卡纸取不出、故障码）→ 联系打印机售后。

**对客户话术**：「我先清一下打印任务，看是不是队列堵了，再检查连接，很快。」

## 4.3 电脑开机无显示 / 开不了机

**现象**：按电源键没反应，或风扇转但屏幕没画面。

**30 秒快速判断**：先判断「有没有电」：主机灯亮不亮、风扇转不转。不转 = 供电问题（插座、电源线、电源开关）；转但无显示 = 显示信号问题（视频线、信号源、内存条）。

**可能原因（按概率）**：
- 高：插座 / 排插没电、电源线松、主机电源开关没开
- 中：视频线松 / 显示器没切对信号源
- 中：内存条松动 / 氧化（台式机经典问题）
- 低：显卡 / 主板 / 电源硬件故障

**排查步骤**：
1. 看主机电源灯和风扇：完全不转 → 换插座（拿别的小电器试）、电源线两端重插、主机背面电源开关确认在「-」位
2. 风扇转但屏幕黑 → 看显示器电源灯（橙色 = 无信号）：视频线两端重插、手动切换显示器信号源
3. 换一根视频线 / 换一台显示器测，排除线和显示器
4. 台式机：断电后开侧盖，把内存条拔下、橡皮擦金手指后重插（先征得机主同意）
5. 接独显的：把线插到主板集显口测一次，判断是不是显卡问题
6. 有无报警声？记下几声蜂鸣，不同主板含义不同，报修时说明

**老师傅提示**：
- 口诀：先电源后信号，先外部后内部。
- 内存条重插是老技术员的肌肉记忆——十台开不了机的台式机，能救回来三台。

**什么时候必须上报**：替换测试确认主板 / 电源 / 显卡故障 → 报修或建议更换；客户机器先征求同意再拆，数据安全放在第一位。

**对客户话术**：「我先做基础检查：电源、线、显示器，这几步能排除大多数'不开机'。」

## 4.4 共享文件夹 / 网上邻居访问不了

**现象**：访问共享文件夹提示无权限 / 找不到网络路径 / 要账号密码。

**30 秒快速判断**：先看「共享那台电脑能不能被 ping 通」：不通 → 先当网络问题处理；通 → 当权限问题处理。用 IP 直访（\\192.168.1.x）通常能绕过名称解析的坑。

**可能原因（按概率）**：
- 高：名称解析问题：看不到「计算机名」，但用 IP 能访问
- 高：权限问题：共享权限 / 安全权限 / 账号密码
- 中：对方电脑防火墙拦了文件共享、来宾访问被禁
- 低：对方电脑没开机 / 共享没开

**排查步骤**：
1. 先 ping 对方电脑 IP：不通 → 按网络问题处理；通 → 继续
2. 资源管理器地址栏输入 \\对方IP —— 能打开 = 名称解析问题（直接用 IP；可写 hosts 固化）
3. 提示要账号密码 → 输对方电脑的账号；或配「所有人可访问」的共享
4. 权限检查：对方电脑右键文件夹 → 属性 → 共享 → 添加 Everyone 读写；再看「安全」标签页给权限
5. 检查对方电脑：防火墙「文件和打印机共享」放行、网络发现打开；Win10/11 默认禁用来宾，用账号方式
6. 重启两台电脑的 Workstation / Server 服务

**老师傅提示**：
- 万能第一招：\\IP 直访——一步区分「网络问题」还是「权限问题」。
- 共享修好后，让对方给这个文件夹配个专门账号，比 Everyone 更稳妥。

**什么时候必须上报**：涉及公司域环境、权限策略 → 找 IT 管理员，不改域内策略。

**对客户话术**：「我先用 IP 直接访问试试，马上能分清是网络还是权限的问题。」

# 光猫（GPON ONT）操作与维护手册

## 一、设备概述

本手册适用于家庭宽带及小型办公场景使用的 GPON 光猫（ONT）。设备通过光纤上联运营商 OLT，向下提供以太网（LAN）与无线（WiFi）接入。

## 二、面板指示灯含义

| 指示灯 | 状态 | 含义 |
|---|---|---|
| PWR 电源 | 常亮 | 供电正常 |
| PWR 电源 | 不亮 | 电源未接或适配器故障 |
| PON 注册 | 常亮 | 已成功注册到运营商网络 |
| PON 注册 | 闪烁 | 正在注册，或光功率不稳定 |
| PON 注册 | 不亮 | 未注册，需检查光纤与账号 |
| LOS 光信号 | 不亮 | 光信号正常 |
| LOS 光信号 | 红灯常亮 | 收不到光信号：光纤断、弯折过度或运营商侧故障 |
| LOS 光信号 | 红灯闪烁 | 光功率过低或波动 |
| LAN 网口 | 常亮/闪烁 | 对应网口已连接，闪烁表示有数据 |
| WLAN 无线 | 常亮 | 无线功能已开启 |

## 三、安装与接线

1. 光纤接头（SC/UPC 或 SC/APC）插入光口时对准缺口，轻推到位，禁止用力旋转。
2. 电源适配器规格一般为 12V/1A，使用非原装适配器可能导致重启或损坏。
3. 网线接入 LAN1 口连接路由器或电脑；如需 IPTV，机顶盒接专用 LAN 口。
4. 设备放置应通风、远离热源，不要叠放杂物遮挡散热孔。

## 四、管理页面登录

1. 电脑通过网线连接 LAN 口，或连接设备默认 WiFi。
2. 浏览器访问默认管理地址，常见为 192.168.1.1，以设备背面标签为准。
3. 默认账号密码见设备背面标签，首次登录后应立即修改。
4. 管理页面可查看光功率、连接状态、已连接设备列表。

## 五、常见故障处理

### 5.1 LOS 红灯常亮
- 检查光纤是否被重物压住、是否弯折（弯曲半径应大于 3 厘米）。
- 拔下光纤重新插紧，注意不要用手触摸光纤端面。
- 确认运营商侧是否在检修；以上无效则报修线路。

### 5.2 PON 不亮或闪烁
- 多为设备未在运营商侧注册：检查宽带账号是否欠费、设备是否被重置。
- 联系运营商确认是否需要重新下发配置。

### 5.3 指示灯正常但无法上网
- 检查电脑是否获取到 IP（应为 192.168.1.x 网段）。
- 确认宽带拨号方式：光猫路由模式下由光猫拨号，桥接模式下需路由器拨号。
- 重启光猫与路由器，间隔 30 秒以上。

### 5.4 无线信号弱或频繁掉线
- 检查设备摆放位置，避免金属柜内、微波炉旁。
- 2.4G 与 5G 分开命名，近距离优先连接 5G。
- 若连接设备过多（超过 20 台），建议外接独立路由器。

## 六、重置方法

用针状物长按 Reset 孔 10 秒以上，指示灯全部熄灭后重新亮起表示重置完成。重置会清除宽带账号与 WiFi 配置，请提前记录。

## 七、安全与注意事项

1. 严禁直视光纤端面与光口，激光可能损伤眼睛。
2. 不要自行拆开设备外壳，内部无用户可维修部件。
3. 雷雨天气建议断开电源与网线。
4. 设备背面标签包含宽带账号信息，不要拍照外传。

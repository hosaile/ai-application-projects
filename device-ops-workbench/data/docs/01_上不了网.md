# 一、上不了网（6 个场景）

> 网络排障助手 知识库 · 共 23 个场景 · 内容整理自实训资料与常见故障处理经验 · 以实际设备为准

## 1.1 整个办公室 / 整栋楼都上不了网

**现象**：客户说「整个办公室都上不了网」，好几台设备同时不行。

**30 秒快速判断**：先确认范围：只有一台电脑，还是好几台、整个办公室？只有一台 → 查「单台电脑上不了网」；全部 → 从光猫和主路由开始。再看光猫指示灯，5 秒判断是线路问题还是设备问题。

**可能原因（按概率）**：
- 高：宽带线路故障：光纤断、欠费、运营商片区故障
- 中：光猫或主路由断电、死机（被踢掉排插最常见）
- 中：停电、跳闸，或排插被碰松
- 低：主交换机故障或上联线松动

**排查步骤**：
1. 看光猫指示灯：电源灯（PWR）亮不亮？光信号 / LOS 灯有没有红灯闪或常亮？红灯 → 光纤线路故障，直接走「光猫指示灯异常」流程
2. 看 PON 灯：常亮 = 注册正常；闪烁 = 正在注册或异常
3. 排除欠费：让客户打运营商客服查一下，或看缴费记录——欠费会整条宽带停机
4. 看主路由 / 主交换机电源灯亮不亮、排插松没松、有没有跳闸
5. 按顺序重启：光猫断电 30 秒 → 上电等 2 分钟 → 主路由 → 主交换机，每级等指示灯稳定
6. 甩开路由器测试：电脑网线直连光猫 LAN 口，能上网 → 问题在路由器；不能上网 → 问题在光猫或线路
7. 光猫正常但全楼不通 → 检查主交换机上联口和各口指示灯，换个上联口试

**老师傅提示**：
- 先数一遍链路：光猫 → 路由 → 交换机 → 终端，再动手。重启不是玄学——设备死机是高频原因。
- 光猫正常但全楼不通，问题大概率在主交换机或它上面的那根上联线。

**什么时候必须上报**：光猫 LOS 红灯 / 欠费 / 运营商片区故障 → 让客户拨打运营商客服报修（电信 10000、移动 10086、联通 10010），帮忙说清现象并记录故障单号。

**对客户话术**：「我先看一下是线路的问题还是设备的问题，几分钟；如果需要报修运营商，我帮您把故障说清楚。」

## 1.2 只有一台电脑上不了网，别人都正常

**现象**：同事都能上网，就这一台电脑不行；右下角可能带黄叹号或红叉。

**30 秒快速判断**：看右下角网络图标：红叉 = 网线没插好 / 网口没通（物理问题）；黄叹号 = 连上了但没拿到地址（IP 问题）；图标正常 = 多半是 DNS 或浏览器问题。再看这台是有线还是无线。

**可能原因（按概率）**：
- 高：网线松动、水晶头坏、网口没插实
- 高：IP 没拿到：显示 169.254 开头地址
- 中：网卡被禁用或驱动异常
- 中：这台电脑的 IP 被别的设备占了（冲突）
- 低：交换机端口故障或被做了限制

**排查步骤**：
1. 看屏幕右下角图标：红叉 / 黄叹号 / 正常，先分类
2. 有线：网线两头重新插紧（听到「咔」），换一根好线再试
3. 无线：确认连的是正确 WiFi；「忘记此网络」后重连；有线无线互相切换测一下
4. 查地址：cmd 输入 ipconfig —— 显示 169.254.x.x = 没拿到地址 → 重启电脑、换个交换机口、确认上级路由 DHCP 开着
5. 地址正常但上不了：ping 网关（如 192.168.1.1）→ 通 = 本机到网关链路 OK，继续下一步；不通 = 换交换机口、换网线
6. 再 ping 114.114.114.114 → 通但网页打不开 = DNS 问题，改成 114.114.114.114 / 223.5.5.5
7. 看网卡是否被禁用：控制面板 → 网络连接 → 灰色「已禁用」的启用一下
8. 检查是不是手动设了固定 IP 且没填对网关、DNS

**老师傅提示**：
- 169.254 开头的地址是 Windows 自己编的临时地址（APIPA），说明它没问到 DHCP 服务器——记住这个数就能秒判「拿不到地址」。
- 同一位置多台电脑先后出问题 → 别折腾电脑，去查那个交换机口。

**什么时候必须上报**：换线换口都无效 → 网卡或电脑硬件问题，建议报修电脑；同一交换机下多台异常 → 上报检查交换机。

**对客户话术**：「先帮您看出是网线、电脑设置还是网络的问题，不影响其他人上网。」

## 1.3 能上微信 / QQ，但打不开网页

**现象**：微信消息能发、视频能刷，但浏览器打不开网页 / 部分网站打不开。

**30 秒快速判断**：这类基本是 DNS 问题——微信走长连接不依赖域名解析，网页必须解析域名。最快验证：同 WiFi 下用手机打开同一网址，手机也打不开 → 网络侧 DNS 问题；只有这台不行 → 这台电脑的问题。

**可能原因（按概率）**：
- 高：DNS 服务器故障或被改错（上级路由/运营商 DNS 出问题）
- 中：电脑上设了错误 DNS 或代理没关干净
- 低：浏览器插件 / 缓存问题

**排查步骤**：
1. 同 WiFi 用手机测同一网址：都打不开 → 改路由器/电脑 DNS；只有这台不行 → 只处理这台
2. 改 DNS：网络适配器 → IPv4 属性 → 首选 114.114.114.114、备用 223.5.5.5 → 再 cmd 运行 ipconfig /flushdns
3. 查代理：设置 → 代理 → 关闭「使用代理服务器」（加速器、某些工具退出后不还原代理，这是高频坑）
4. 换浏览器测：排除插件问题，或用无痕模式
5. 用 ping 域名判断：ping www.baidu.com —— 提示「找不到主机」= 解析问题确认；能解析出 IP 但网页打不开 = 网络侧端口拦截

**老师傅提示**：
- 公共 DNS 记三个：114.114.114.114、223.5.5.5（阿里）、119.29.29.29（腾讯），现场换着试。
- 「微信能上网页打不开」= DNS；「网页能开微信不能上」= 少见，多半是代理工具作怪。

**什么时候必须上报**：全办公室都打不开网页且换 DNS 无效 → 上联网络或运营商问题，报上级 / 运营商。

**对客户话术**：「这是域名解析的问题，我改一下 DNS 设置就好，两三分钟。」

## 1.4 网速慢、卡顿

**现象**：能上网但很慢：网页转圈、视频卡、下载慢。

**30 秒快速判断**：先问「一直慢还是突然慢、是一台慢还是都慢」：一台慢 → 查这台（线/无线位置）；都慢 → 查带宽占用和主设备。再分有线/无线测一次对比。

**可能原因（按概率）**：
- 高：有人下载 / 看视频 / 网盘同步，占满带宽
- 中：无线信号差、干扰大（离得远、隔墙多、2.4G 拥挤）
- 中：路由器长时间没重启、设备老化
- 低：网线只通了百兆（四芯线 / 水晶头没压好）
- 低：宽带套餐本身带宽小

**排查步骤**：
1. 区分有线 / 无线：有线也慢 → 查带宽占用和线路；只有无线慢 → 查位置、隔墙、信道
2. 问一圈「谁在下载」：迅雷、网盘、视频、系统更新都会占满带宽，抓到一个就解决一半
3. 测速对比：手机上测速，对照套餐带宽（100M 宽带理论下载约 12.5MB/s）
4. 重启顺序：光猫 → 路由，每级等 1-2 分钟
5. 有线慢：检查网线是否八芯全通——百兆只用 4 芯，只压 4 芯的线千兆跑不满；重压水晶头或换线
6. 无线慢：靠近路由器再测一次对比；切到 5G 频段测；路由器里把信道改成 1 / 6 / 11 中空闲的
7. 设备用了 4-5 年的路由器建议直接更换

**老师傅提示**：
- 千兆网络必须八芯全通 + 超五类以上网线。「能上网但只有百兆」的坑，多半是线的问题。
- 「一直慢」和「突然慢」是两个排查方向，先问清再动手。

**什么时候必须上报**：有线直连光猫测速仍远低于套餐 → 让客户找运营商查线路。

**对客户话术**：「我先帮您测一下速，看看是宽带本身慢，还是有人在占网速。」

## 1.5 WiFi 连上了但没网 / 信号弱

**现象**：手机显示已连接 WiFi 但打不开东西；或某些位置信号只有一格。

**30 秒快速判断**：先看别的设备连这个 WiFi 能上网吗：都不能 → 查路由器 / 上级（WiFi 只是「连接上了」，不代表有网）；就这一台不行 → 忘记网络重连；只有某个区域不行 → 覆盖问题，和路由器位置有关。

**可能原因（按概率）**：
- 高：路由器死机或本身已断网（WiFi 信号在，但出不去）
- 高：覆盖不足：路由器位置差、隔墙多、面积大
- 中：信道拥挤（周围 WiFi 太多互相干扰）
- 中：这台设备的问题：没获取到地址、密码变了没重连
- 低：无线 AP 故障

**排查步骤**：
1. 拿另一台设备连同一 WiFi 测：判断是「网络问题」还是「这一台的问题」
2. 都不能上网 → 按「整栋上不了网」流程查路由器和上级；顺便重启路由
3. 只有一台连上没网 → 「忘记此网络」重连；查是否拿到 169.254 地址
4. 覆盖问题：路由器别放角落、弱电箱、地上——放居中、高处、少遮挡；大户型加 AP / 子路由
5. 2.4G 和 5G 分开测：5G 快但穿墙差，远距离试用 2.4G
6. 人多干扰重：路由器里把信道改成 1 / 6 / 11 里较空闲的

**老师傅提示**：
- 金属弱电箱是 WiFi 杀手——箱门一关信号掉一半，能引出来就引出来。
- 「WiFi 能连上」≠「有网」，这两件事分开判断能少走很多弯路。

**什么时候必须上报**：大平层 / 多层覆盖不足 → 向客户提交加 AP 的方案；路由器本身故障 → 建议更换。

**对客户话术**：「我帮您测一下哪个位置信号弱，路由器摆放对 WiFi 影响很大，稍后给您一个建议。」

## 1.6 网络时断时续（一会好一会断）

**现象**：网络一会儿断一会儿好，重启能用一阵又出问题。

**30 秒快速判断**：先固定一台设备持续 ping 网关观察：是一台断还是全体断？一台 → 查这台的网线和水晶头（接触不良最常见）；全体 → 查上级设备、IP 冲突、环路。

**可能原因（按概率）**：
- 高：水晶头 / 网线接触不良（碰一下就好、晃一下又断）
- 中：IP 地址冲突：两台设备抢一个地址互相踢
- 中：网络环路：接线接成圈引起广播风暴
- 低：设备过热或电源不稳

**排查步骤**：
1. 持续观察：cmd 里 ping 网关 -t，看是否周期性丢包；断的时候是一台还是全体
2. 一台设备频繁断 → 换网线、重做水晶头：重点看水晶头压得松不松、线序乱不乱
3. 全体一起断 → 看交换机指示灯是否全部狂闪 → 疑似环路，走「网络环路」流程
4. 查 IP 冲突：Windows 会弹「检测到 IP 地址冲突」；把冲突的两台改成自动获取或重排地址
5. 摸光猫 / 路由 / 交换机外壳温度：烫手且伴随断网 → 散热差或老化，移位置通风或更换
6. 记录断网时间规律：几点断、断多久——有规律多半和负载 / 温度有关，是找根因的线索

**老师傅提示**：
- 排「时断时续」最忌没重点瞎换：先定范围（一台还是全体），范围一确定，一半的问题就定了。
- 水晶头做得好不好，手拉一下就知道——一拉就掉、铜丝外露的，直接换。

**什么时候必须上报**：全体设备周期性断、重启无用 → 记录现象和时间点，上报并附上观察记录。

**对客户话术**：「这种一阵一阵的问题得先看规律，我固定几台设备观察一下，有结果马上处理。」

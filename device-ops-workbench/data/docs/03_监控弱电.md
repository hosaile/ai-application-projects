# 三、监控弱电（5 个场景）

> 网络排障助手 知识库 · 共 23 个场景 · 内容整理自实训资料与常见故障处理经验 · 以实际设备为准

## 3.1 摄像头离线（NVR / 平台显示离线）

**现象**：NVR 或手机上看监控，某个摄像头显示「离线」。

**30 秒快速判断**：到摄像头跟前看两个灯：电源灯亮不亮、网口灯闪不闪。不亮 → 查供电（电源 / PoE）；亮但离线 → 查网络（网线 / IP）。一灯一灯排除，别在 NVR 上瞎点。

**可能原因（按概率）**：
- 高：供电问题：电源适配器坏、PoE 口没电、断电
- 高：网线水晶头松动 / 氧化（室外尤其常见）
- 中：IP 冲突或被改（和别人撞地址）
- 中：NVR / 平台里通道配置丢失、密码被改
- 低：摄像头本体故障 / 交换机端口坏

**排查步骤**：
1. 到摄像头处看灯：电源灯不亮 → 先查供电（电源头、插排、PoE 口）
2. 电源灯亮、网口灯不闪 → 网线问题：两端重插，水晶头重做（室外头子进水氧化是常态）
3. 灯都正常仍离线 → 电脑用 SADP 扫一下，看能不能搜到、记下 IP
4. 搜到但 NVR 连不上 → 电脑先 ping 摄像头 IP：通 → 查 NVR 通道配置 / 密码；不通 → 查网络链路
5. 电脑也搜不到 → 摄像头直连电脑测试（电脑 IP 改成同网段），还不行 → 长按 Reset 恢复出厂后重新配置（会清空原设置，谨慎用）
6. 恢复后：更新 NVR 通道、对照 IP 清单核对、把线序和端口标记好
7. 排查 IP 冲突：查 IP 规划表，或在交换机上看这个 IP 有没有对应的两个 MAC

**老师傅提示**：
- 室外网线必须做防水（端口朝下 + 防水头）。室外离线九成是水晶头进水。
- SADP 是海康官方免费扫描工具，电脑装一个，现场必带；大华对应 ConfigTool。

**什么时候必须上报**：直连电脑也不出图 → 摄像头硬件故障，联系供应商保修 / 更换；涉及高空作业（外墙）→ 必须两人配合，不独自登高。

**对客户话术**：「我先到摄像头那里看看电源和线，大部分离线都是接头或供电的问题，很快能判断。」

## 3.2 监控画面黑屏 / 有电但没图像

**现象**：监控能连上，但画面全黑 / 某个通道黑 / 画面花。

**30 秒快速判断**：先看范围：所有通道黑 → 查 NVR 输出线和显示器；只有一个通道黑 → 查这一个摄像头；夜间黑、白天正常 → 查红外 / 供电。

**可能原因（按概率）**：
- 高：单通道黑：该摄像头问题（走「摄像头离线」流程）
- 中：全部黑：NVR 到显示器的视频线松、显示器信号源不对
- 中：夜间黑、白天正常：红外灯故障或供电不足
- 低：镜头脏 / 被挡 / 镜头盖没摘
- 低：NVR 死机或通道异常

**排查步骤**：
1. 区分范围：一个通道黑，还是全部黑？
2. 全部黑 → 检查 NVR 的 HDMI / VGA 线两端、显示器信号源切对没有、重启 NVR
3. 单通道黑 → 按「摄像头离线」流程查这个摄像头
4. 白天正常、晚上黑 → 供电不足或红外灯坏：换足功率电源（12V/2A 常见）、检查线路压降
5. 花屏、水波纹、有横纹 → 线材质量 / 接头氧化 / 电源不干净：换线、换电源，走线避开强电
6. 擦干净镜头外壳，确认没被蜘蛛网、树叶遮挡

**老师傅提示**：
- 「白天好、晚上黑」几乎等于供电或红外问题——别在网络上浪费时间。
- 画面问题先看线再看设备：换线、换电源能解决大部分画面异常。

**什么时候必须上报**：更换测试确认摄像头故障 → 换新；需要登高 → 两人配合再上。

**对客户话术**：「我看下是摄像头的问题，还是录像机这边的问题，分开排查一下很快清楚。」

## 3.3 NVR 搜不到 / 加不上摄像头

**现象**：新装或换线后，NVR 搜不到摄像头，或添加后不出画面。

**30 秒快速判断**：三个「对」：网段对不对（摄像头和 NVR 同不同段）、协议对不对（私有协议 / ONVIF）、密码对不对。先扫网段，再谈其它。

**可能原因（按概率）**：
- 高：网段不对：NVR 和摄像头不在同一网段
- 中：添加时协议选错（同品牌私有 / 混装 ONVIF）
- 中：用户名密码不对，或摄像头被改过密码
- 低：交换机 VLAN 隔离、网线问题

**排查步骤**：
1. 电脑用 SADP 扫描：确认摄像头在线，记下 IP 和网段
2. 对比 NVR 的内网卡网段：不一致 → 改摄像头 IP 到 NVR 网段，或改 NVR 内网卡网段
3. 手动添加通道：填对 IP、协议（同品牌选私有 / 自动，不同品牌选 ONVIF）、端口、账号密码
4. 密码不对：海康新设备首次使用要先「激活」自己设密码；被改过 → 用原密码或 Reset 重来
5. 添加成功但不出画面 → 删掉通道重新添加一遍；检查主 / 子码流设置
6. 换交换机口、直连 NVR 测试，排除链路问题

**老师傅提示**：
- 不同品牌混装（海康头 + 大华 NVR）必须走 ONVIF，还要在摄像头里打开「ONVIF 功能」——最常见的加不上原因。
- 打电话问厂商技术支持时，直接报设备型号组合，效率最高。

**什么时候必须上报**：反复添加不成功 → 记录型号组合，联系厂商技术支持。

**对客户话术**：「新设备接入要对齐三样：地址、协议、密码，我逐个核对一下。」

## 3.4 PoE 摄像头不上电

**现象**：摄像头完全不亮（无灯），PoE 交换机口不供电或供电不正常。

**30 秒快速判断**：三查：① 交换机是不是 PoE 款、这个口支不支持 PoE；② 摄像头功率超没超单口标准；③ 线是不是太长 / 太差（超 100 米或劣质线压降大）。

**可能原因（按概率）**：
- 高：交换机非 PoE，或该口不支持 / 被关闭
- 高：网线超长（>100 米）或线质太差
- 中：摄像头功率大于单口供电标准、整机总功率超了
- 低：摄像头是非 PoE 型号（需要外接 12V 电源）
- 低：PoE 口芯片坏

**排查步骤**：
1. 确认交换机：看型号和「PoE 总功率」标注；非 PoE 交换机 → 必须加 PoE 供电器或接电源
2. 确认摄像头是 PoE 款（型号带 PoE 或看接口说明）——非 PoE 款必须接 12V 电源
3. 换个已知能供电的 PoE 口测试 → 能上电 = 原口问题或功率分配问题
4. 查线长线质：超过 100 米必须加中继 / 用光纤；用一根短网线直连测试——短线上电 = 线的问题
5. 算功率：普通枪机 / 球机按 802.3af（15.4W）/ 802.3at（30W）算；多路摄像头总和接近交换机总功率时，后接的上不了电 → 错峰接或换大功率交换机
6. 室外网口进水 / 氧化也会供电异常 → 重做水晶头并做防水

**老师傅提示**：
- 记两个数：网线有效距离 100 米；PoE 单口 af≈15.4W、at≈30W。
- 「短线能上电、长线不上电」= 线长或线质问题，不用怀疑设备。

**什么时候必须上报**：确认交换机口坏 → 换口或报修；工程需要加中继 / 换设备 → 报方案和材料。

**对客户话术**：「我在判断是交换机供电的问题还是线的问题，短接测一下马上清楚。」

## 3.5 画面卡顿 / 花屏 / 水波纹

**现象**：画面不流畅、有横纹、波纹，偶尔马赛克。

**30 秒快速判断**：一个通道卡 → 查那一路的线和电源；全部通道都卡 → 查 NVR 性能和交换机带宽；有规律横纹 / 水波 → 强电干扰或电源不干净。

**可能原因（按概率）**：
- 高：网线质量差 / 水晶头氧化，丢包导致卡顿
- 中：电源不达标，或和强电捆在一起走线受干扰
- 中：交换机带宽不够 / 级联层数太多
- 低：码流设置过高、NVR 解码能力不足
- 低：摄像头图像传感器老化

**排查步骤**：
1. 确认范围：一个头卡单独处理；全部卡 → 查交换机和 NVR
2. 单通道：拿一根成品好网线明线测试 → 好了 = 原线路问题（重做水晶头 / 换线）
3. 检查走线：网线和 220V 电源线有没有捆在一起平行走 → 分开走线
4. 换干净的 12V 电源；PoE 供电不足也会花屏
5. 全部卡：登录 NVR 检查码流，适当降低主码流；确认交换机是不是百兆带多路高清（多路 400 万以上建议千兆）
6. 替换法确认：换头测试后仍花屏 → 摄像头老化，换一台验证

**老师傅提示**：
- 花屏 / 水波纹的排查顺序：线 → 电源 → 干扰 → 设备。前两项解决八成问题。
- 双绞线和强电分槽走线，这是施工规范，不是讲究。

**什么时候必须上报**：替换测试确认摄像头坏 → 报修 / 更换；需要重新布线 → 报方案。

**对客户话术**：「画面问题一般是线或电源引起的，我用替换法测一下就能找到原因。」
